# Oh Tidepool public site

The public website for [Oh Tidepool](https://oh-tidepool.nduwork.com/), a free
iPhone app for exploring tidepools, and the content the app
downloads.

| Path | What it is |
| --- | --- |
| `index.html`, `support.html`, `privacy.html` | The landing page, support and FAQ, and privacy policy |
| `licenses.html`, `app-media-credits.html` | Licences, data sources, and photo credits |
| `data/`, `api/public/`, `media/` | Published content the app reads |
| `licenses/cari/` | GPL-3.0-or-later Corresponding Source for the CARI-derived shoreline outlines |

Photographs keep their original licences; see the
[credits page](app-media-credits.html). Questions:
[support@nduwork.com](mailto:support@nduwork.com).
