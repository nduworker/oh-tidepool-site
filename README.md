# Oh Tidepool public site

This repository intentionally contains only the public Oh Tidepool landing page
and privacy policy. It is published with GitHub Pages at
`https://nduworker.github.io/oh-tidepool-site/`.

The iPhone app source, development documentation, credentials, and operations
materials remain in the separate private application repository.

The `media/` directory publishes the app's reviewed, versioned WebP
renditions. The iPhone catalog resolves an asset with ID `bat-star` and
revision `1` as `media/bat-star-v1.webp`; filenames are immutable so GitHub
Pages and the on-device cache can safely retain them.
