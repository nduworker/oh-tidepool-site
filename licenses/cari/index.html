CARI rocky-shore geometry

This directory is the Corresponding Source for the rocky-shore outlines that ship inside the Oh Tidepool iPhone app. The app's licence text sends readers to this address, so the files below are the material that has to be available: the geometry as bundled, the script that produced it, and the full licence text.

What the importer does

The importer selects the CARI RS polygons that intersect a 350 m radius around each site's reviewed anchor, then applies a 1 m Douglas-Peucker simplification in a local metre frame. It writes the geometry back in WGS84 as GeoJSON. Polygons are selected, never crop-clipped, so the original ring edges are kept rather than replaced with a fabricated circular boundary. It is an offline curation tool, not something the app calls at request time.

What this geometry is not

Each outline is a static mapped rocky-intertidal boundary. It is not a predicted waterline, navigational chart, safe route, or real-time access condition, and it carries no claim about whether a visit is safe or permitted.
